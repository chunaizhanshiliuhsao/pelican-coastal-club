# 鹈鹕海岸骑行俱乐部

一个温暖、松弛的实时 3D 鹈鹕骑行页面。场景由原创程序化模型组成，渲染库随项目提供，无需网络、安装依赖或构建。

## 一键打开

双击根目录的 **打开鹈鹕骑行.html**。也可以双击 **启动项目.cmd**，或直接打开 `dist/index.html`。

建议使用近期版本的 Edge、Chrome、Firefox 或 Safari，并启用浏览器硬件加速。无需 Node.js、Python 或任何开发环境。

## 交互

- 拖动场景：自由旋转视角；滚轮：缩放。
- 空格：暂停或继续骑行；B：打铃；C：切换镜头。
- 骑行节奏：调整速度，车轮、踏板、双脚及链条一起响应。
- 海岸 / 跟骑 / 特写：切换镜头。
- 日落 / 晴日：平滑切换天空、海面与照明。
- 海风：开启或关闭本地合成的环境声音。默认静音。
- 留影：下载带有日期的 PNG 海岸明信片。
- 路面石子、路缘随骑行后退；三层连续山脉、山间小路、亭子和小屋随景移动，形成远近视差。
- 检测到系统偏好“减少动态效果”时，初始骑行暂停，可主动继续。

## 项目文件

`dist/index.html` 页面结构；`dist/style.css` 响应式布局；`dist/app.js` 3D 场景、动作和交互；`dist/vendor/three.min.js` 离线渲染库。

Three.js r160.1 采用 MIT 许可，完整许可位于 `dist/vendor/THREE-LICENSE.txt`。其余模型和页面均为本项目原创程序化实现，不包含下载的角色模型、字体、图片或音乐。

## 本地开发（可选）

安装 Node.js 后，在此目录运行 `node preview.cjs`，浏览器访问终端显示的本地地址。开发服务器仅监听本机。

运行 `node tests/motion.cjs` 可检查场景移动方向、调速与暂停、长距离循环连续性，以及山体拼接处的高度、法线和颜色。

页面不采集数据、不需要账号，也不向外部服务上传明信片。骑行里程仅记录当前页面会话。
